Техническое задание: Билетная система для сети кинотеатров на PyQt

1. Общие требования

Разработка графического приложения для управления сетью кинотеатров, включая функционал бронирования билетов, управления расписанием и информацией о кинотеатрах.


2. Функциональные требования

2.1. Модуль управления кинотеатрами

Вкладка "Кинотеатры"

· ✅ Добавление нового кинотеатра
· ✅ Редактирование информации о существующем кинотеатре
· ✅ Удаление кинотеатра
· Поля данных:
  · Название кинотеатра
  · Адрес
  · Контактный телефон
  · Дополнительная информация

2.2. Модуль управления кинозалами

Вкладка "Кинозалы"

· ✅ Добавление нового кинозала
· ✅ Редактирование информации о кинозале
· ✅ Удаление кинозала
· Поля данных:
  · Название/номер зала
  · Вместимость (количество мест)
  · Принадлежность к кинотеатру

2.3. Модуль управления фильмами

Вкладка "Фильмы"

· ✅ Добавление нового фильма
· ✅ Редактирование информации о фильме
· ✅ Удаление фильма
· Поля данных:
  · Название фильма
  · Продолжительность
  · Постер (опционально)

2.4. Модуль расписания сеансов

Вкладка "Сеансы"

· ✅ Добавление сеанса для фильма в конкретном кинозале
· ✅ Редактирование расписания
· ✅ Удаление сеанса
· Поля данных:
  · Фильм
  · Кинозал
  · Дата и время начала сеанса
  · Цена билета

2.5. Модуль афиши

Вкладка "Афиша"

· ✅ Просмотр фильмов, идущих в конкретный день
· ✅ Фильтрация по кинотеатрам
· ✅ Отображение доступных сеансов
· ✅ Возможность перехода к бронированию

2.6. Модуль бронирования билетов

Вкладка "Бронирования"

· ✅ Просмотр всех забронированных билетов
· ✅ Фильтрация по дате, кинотеатру, фильму
· ✅ Отмена бронирования
· Информация о брони:
  · Номер брони
  · Фильм и сеанс
  · Места
  · Статус брони
  · Контактные данные клиента

3. Интерфейс пользователя

3.1. Главное окно

· Меню: Файл, Справка
· Панель вкладок:
  1. Кинотеатры
  2. Кинозалы
  3. Фильмы
  4. Сеансы
  5. Афиша
  6. Бронирования

4.1. Структура базы данных

Таблица cinemas

· id INTEGER PRIMARY KEY
· name TEXT NOT NULL
· address TEXT
· phone TEXT
· description TEXT

Таблица halls

· id INTEGER PRIMARY KEY
· cinema_id INTEGER FOREIGN KEY
· name TEXT NOT NULL
· capacity INTEGER
· hall_type TEXT
· equipment TEXT

Таблица movies

· id INTEGER PRIMARY KEY
· title TEXT NOT NULL
· genre TEXT
· duration INTEGER
· age_rating TEXT
· director TEXT
· actors TEXT
· description TEXT
· poster_path TEXT

Таблица sessions

· id INTEGER PRIMARY KEY
· movie_id INTEGER FOREIGN KEY
· hall_id INTEGER FOREIGN KEY
· datetime DATETIME
· price DECIMAL(10,2)

Таблица bookings
· id INTEGER PRIMARY KEY
· session_id INTEGER FOREIGN KEY
· customer_name TEXT
· customer_phone TEXT
· customer_email TEXT
· seats TEXT
· booking_time DATETIME
· status TEXT
